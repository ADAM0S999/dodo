📡 ADAM REST API Gateway

          
Send WhatsApp messages and receive incoming webhooks programmatically from your CRM or dashboard.

        


        

          

            

              

                GET
                /api/health
              

              
Returns service status, uptime, and bot readiness.

            


            

              

                POST
                /api/pair
              

              
Requests an 8-character pairing code for any phone number.

            


            

              

                POST
                /api/send
              

              
Sends text or media to a target JID or phone number.

            

          


          

            
Sample cURL to Send Text:

            
curl -X POST https://lm7bos.vercel.app/api/send \
  -H "x-api-key: your-secret-key" \
  -H "Content-Type: application/json" \
  -d '{
    "to": "212612345678",
    "type": "text",
    "text": "Hello from ADAM API!"
  }'
